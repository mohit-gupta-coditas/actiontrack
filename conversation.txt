**1. Argument parsing (commander, no hand-parsing of `argv`)**
- `-h` / `--help` prints usage and `-v` / `--version` prints the version, both exiting 0. Before this change, `-v` wasn't supported.
- Flags work before arguments (`ingest --json notes/`), and anything after `--` is treated as a positional argument (`done -- 12`).

**2. Exit codes**

| Case | Before | Now |
|---|---|---|
| Success, `-h`, `-v` | 0 / 1 for `-v` | **0** |
| Unknown item id, missing folder, ambiguous owner | 1 | **1** |
| No command, unknown option, missing or invalid argument (`done abc`, `--status x`) | 1 | **2** |
| Unknown command (`actiontrack bogus`) | 1 | **127** |
| Ctrl+C | not handled | **130** |

**3. Output channels**
- **stdout** carries only results: the list table, the ingest summary, the email, the `done` confirmation, and all `--json` output. `--json` output can always be piped straight into another tool.
- **stderr** carries everything else: the skipped-file and ambiguous-owner warnings, "No matching items", "Preview only; nothing was sent", and all errors.

**Fixed along the way:**
- **Database left open:** the new tests showed commands never closed the database, which locks the file on Windows. Each command now closes it when done.
- **Early pipe close:** `actiontrack list | head` now exits 0 instead of crashing.

The README has a new Conventions section with the exit-code table. Setting `DEBUG=1` prints stack traces for unexpected errors.
